Features

Sample data generated in the page. Each card names the spec fields or options it shows.

Zoom, pan and brush, linked to a second chart

zoom: "x", brush: "x", onBrush, onZoom. Drag to brush, Shift-drag to pan, Ctrl/⌘-scroll or pinch to zoom, double-click to reset. Keyboard: + / − / 0, Shift+arrows, [ and ] on a focused point. The bars show the brushed days through sel.filters.

Live data

appendRows(rows, { max: 240 }) every 250 ms: one draw per frame, the oldest rows drop off.

Transform, small multiples, lines over bars

transform buckets daily rows by month and sums them; facet draws one panel per region on shared axes; line adds a target over the bars.

Dense scatter, textures, shadcn tokens

density: "auto" turns 30,000 points into hexagons; patterns: true keeps series apart without colour; theme: "shadcn" reads --chart-1 to --chart-5.
