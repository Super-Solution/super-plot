Super Plot examples

  • Gallery and playground (vanilla, all chart types, theme switch, CSS-variable override)
  • React (<SuperPlot>, memoized spec, onSelect)
  • Web component (<super-plot>, one script tag)
  • Many points (up to 50,000 dots: automatic canvas and WebGL renderers, hover and legend still work)
  • Maps (choropleth, bubbles, 3D columns, raised regions, flows; flat or globe; drag, turn, zoom; import your own boundaries)
  • Showcase (one self-contained page: every chart, light and dark, restyled)

Server-side: node examples/node/render-svg.mjs after npm run build.
